Editor Configuration Builder

Arraste os ícones dos plugins para montar a toolbar. A configuração de plugins e toolbar usada pelo createEditor é gerada automaticamente, com preview ao vivo.

Plugins

Todos os plugins ficam sempre ativos. Arraste uma linha inteira ➜ para dentro de uma linha da toolbar para adicioná-la — ela some daqui e volta quando for removida da toolbar. O separador pode ser usado quantas vezes quiser.

    Presets

    Escolha um cenário de uso pronto — ele monta os plugins e a toolbar automaticamente, substituindo a configuração atual.

    Toolbar

    Solte em qualquer ponto da linha para montá-la. Arraste um botão de volta para o painel de plugins para removê-lo.

    Editor real, montado com a configuração atual.
